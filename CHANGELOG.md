## 0.1.0

Released on 2026-05-01

### Features

- Author-wise contribution statistics
- Metrics supported:
  - Commits
  - Files changed
  - Lines of Code (LOC)
  - Insertions / Deletions
  - Net changes
  - Churn
- Multi-repository support
- Configurable CLI options (metrics, limit, etc.)
